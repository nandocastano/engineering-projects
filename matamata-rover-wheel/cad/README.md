# CAD

SolidWorks model of the wheel and the cut files used for the prototype.

| File | Contents |
|---|---|
| `Assem.SLDASM` | Full assembly |
| `p1.SLDPRT`, `p2.5.SLDPRT`, `p3.SLDPRT`, `p4.SLDPRT` | Individual parts |
| `Bars.STL` | The six connector bars as one frame, for laser cutting |
| `Core Laser Cut.STL` | One layer of the stacked core, for laser cutting |

Renders of the assembly are in `../images/cad_assembled.png` and `../images/cad_exploded.png`.
